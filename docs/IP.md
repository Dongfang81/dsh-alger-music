# 🐰 月宝 Moony — 宠物 IP 定义

> 圆脸 + 耳朵：所有宠物**共用圆形脸**，靠不同**耳朵**（造型 / 颜色 / 动效）区分身份；
> 圆脸可装载贴图、明星照片或表情（未来支持动效表情）。

## 核心视觉

- **圆脸**：统一的圆形面部容器，可装载任意内容（照片 / 贴图 / 表情 / 动效表情）。
- **耳朵**：身份与状态的载体 —— 造型、颜色、动效共同表达"我是谁"以及"播放器 / agent 在做什么"。

## 宠物多样性（同一圆脸，不同耳朵）

| 维度 | 说明 |
| --- | --- |
| 耳朵造型 | 不同 pet 有不同耳型：圆耳 / 兔耳 / 垂耳 / 尖耳 / 折耳… |
| 耳朵颜色 | 每只 pet 的主色（可渐变） |
| 耳朵动效 | 状态动效：摆动 / 探看 / 颤抖 / 点头… |

## 圆脸内容

- 贴图 / 明星照片（当前：正在演唱的歌手照片）
- 表情（静态；未来可做动效表情）

## 状态动效约定（agent 状态 → 耳朵）

| agent 状态 | 耳朵颜色 | 耳朵动效 |
| --- | --- | --- |
| 空闲 idle | 默认色 | 无 |
| 处理中 running | 🔵 蓝 | 快速摆动 |
| 等你确认 waiting | 🟠 橙 | 缓慢探看 |
| 出错 failed | 🔴 红 | 颤抖 |
| 待审查 review | 🟢 绿 | 轻点头 |

**系列 5 只宠物**（同一圆脸，耳朵即身份，浮窗内「宠物」选择器切换、localStorage 记忆）：

- **圆脸** = 歌手头像（作者照片，随当前歌曲自动切换，缺省回退专辑封面 / 🎵）
- **耳朵** = 各宠物专属造型；agent 状态仍覆盖耳朵颜色 + 动效（造型=身份，颜色/动效=状态）
- **配套能力**：唱歌浮动、歌词气泡（marquee 流动）、宠物说话（`alger_say`）、点歌/加队列自动播报
