# 🐰 月宝 Moony — 宠物 IP 定义

Moony 是以统一“月面内容容器”为母体的 2.5D 软胶音乐宠物系列。角色本色、耳朵剪影、可选尾巴与待机节奏共同构成身份；圆脸不承载传统五官。

## 不可变母体

- 空闲圆脸是完全无五官的空白月面。
- 歌手照片或唱片封面出现时，占据完整圆面，不叠加表情、Emoji 或月球纹理。
- 脸只承载内容；耳朵与可选尾巴负责身份和情绪。
- 耳朵采用统一耳根、双层软胶轮廓、内层月纹和耳尖信号灯。
- 角色本色永远保留；running / waiting / failed / review 只改变信号灯、轮廓光和动作。

## 造型语言

- 所有角色共用圆脸尺寸、边框厚度、材质光影和媒体裁切规则。
- 耳朵来自可辨认的动物远亲轮廓，但经过统一的月化处理，不使用字面的兔、猫、狐或犬皮肤。
- 尾巴为可选身份结构；有尾角色借此补充情绪与节奏，无尾角色以双耳角度、节奏和不对称动作表达。
- DSH 内使用 DOM、CSS 与内联 SVG 实现圆润厚边、有限高光和单层体积阴影；完整 3D 是未来宣传与实体商品的延展，不属于当前实现。

## 状态表达

状态色只进入耳尖灯和外轮廓光，绝不替换整只耳朵的角色本色。

| agent 状态 | 信号色 | 动作 |
| --- | --- | --- |
| idle | 熄灭 | 角色自然待机动作 |
| running | 蓝 | 双耳交替摆动 |
| waiting | 橙 | 耳朵向前探听 |
| failed | 红 | 短促抖动三次后停止 |
| review | 绿 | 双耳缓慢点头 |

播放律动位于整体节奏层，agent 状态动作位于耳朵与尾巴层；两者可以组合。启用“减少动态效果”时，持续摆动、漂浮与律动关闭，仅保留静态信号色。

## 系列成员

- Moony Classic：常驻初代，蓝紫圆耳，指向经典版与 classical music。
- Moony · Pulse：节拍追逐者，无尾。
- Moony · Echo：回忆共振者，环形尾。
- Moony · Drift：沉浸漂流者，彗尾。
- Moony · Spark：新声探索者，无尾。
- Moony · Chorus：跟唱共鸣者，卷尾。
- Moony · Hush：安静陪伴者，无尾。

Moony Classic 为默认选择；First Wave 的六名成员以不同耳朵剪影、固定角色本色和待机节奏表达各自的听歌方式。

## 内容与异常回退

- 有效媒体 URL 显示歌手照片或唱片封面；没有内容、URL 缺失或图片加载失败时，一律显示空白圆脸。
- 未知角色 ID 或角色字段缺失时回退 Moony Classic；未知 agent 状态回退 idle。
- 角色选择保存于版本化浏览器本地键 `dsh-moony-singer:pet-id:v1`；读写失败不影响当前会话。
- 单只角色或媒体异常不得阻断音乐播放器控件或 DSH 客户端加载。

## 接入边界

本系列只在现有客户端入口内部组织角色数据、状态解析和宠物渲染。不改变模块加载方式、`apply(ctx)`、客户端 inject、侧边栏 slot、服务端路由、工具或 `cordis.patch.yml`。
