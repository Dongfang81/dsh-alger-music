# 🎵 dsh-moony-singer · 月宝 Moony

> **你的 DSH 会唱歌了。** 一只会跟着音乐律动的月亮宠物，一个装完即用的音乐播放器——
> 不装任何桌面 App，不配任何端口，装上插件，开口点歌。

---

## 🌟 三大亮点

**① 在对话框说一句「我想听歌」，宠物就给你安排好**
不用打开任何 App、不用输入歌名——直接说「我想听歌」「来点轻松的」，月宝自动从推荐歌单里挑出应景的音乐整单开播，还会在气泡里告诉你它在放什么。

**② 七只可爱 Moony，随你的音乐翩翩起舞**
常驻初代 Classic + 六只 First Wave 成员（Pulse / Echo / Drift / Spark / Chorus / Hush），每只都有专属耳型、本色与听歌律动。播放时圆脸亮起歌手/专辑画面，耳朵和尾巴跟着节拍摇摆——情绪价值拉满。

**③ 会学习你的听歌习惯和场景（开发中）**
月宝正在学习你常听的歌与播放时机，未来会在你工作疲劳时主动推荐应景的歌曲，做一个真正懂你的音乐搭子。

## ✨ 为什么它值得你装上

**「在对话里说一句『放首歌』，它真的会唱给你听。」**

- 🚀 **零依赖安装即用**——不需要安装任何音乐播放器，插件自带音乐服务 + 浏览器播放引擎，装完就能搜歌、点歌、听歌
- 🎤 **AI 原生体验**——在对话里说「播放 周杰伦」「来点轻松的歌单」「推荐点新歌」，它直接开播，还能听懂「下一首」「暂停」
- 🐰 **月宝 Moony 会唱歌**——播放时跟着旋律律动，歌词一句句在气泡里浮现；它还**长着耳朵感知你的 DSH**：蓝色=正在干活、橙色=等你审批、红色=出错、绿色=待审查
- 🧩 **七只 Moony 任你切换**——点「变身」随时换装
- 🖱️ **浮动小窗随叫随到**——右下角悬浮，拖动、折叠、隐藏；播放列表、进度条、收藏、播放模式一应俱全
- 🔒 **本机优先、安全隔离**——音乐服务只监听 127.0.0.1，绝不外泄

## 🐰 月宝 Moony · 宠物 IP

Moony 系列：**圆脸 + 耳朵**。所有宠物共用圆形月面（可装载歌手照片/专辑封面），
身份与情绪由月化耳朵、可选尾巴、耳尖信号灯和听歌律动表达。

![Moony Classic 与 First Wave](docs/moony-series.png)

- 空闲时圆脸完全留白；播放时圆脸只显示歌手或唱片内容
- 七只角色各有专属耳型、本色与听歌律动节奏
- 展开浮窗点「变身」即可切换，选择本地保存
- 完整 IP 规范见 [docs/IP.md](docs/IP.md)

## 🧰 工具清单（给模型用的能力）

| 工具 | 说明 |
| --- | --- |
| `alger_play` | 点歌：`songId` 或 `keyword`，立即播放 |
| `alger_search` | 搜索歌曲/专辑/歌单/歌手 |
| `alger_recommend` | 随机推荐歌单，整单播放 |
| `alger_queue` | 播放列表：追加/整批加入/插播/整单播放/跳转/清空 |
| `alger_control` | 播放/暂停/切歌/音量/收藏/播放模式 |
| `alger_status` | 当前播放、进度、收藏、模式 |
| `alger_song` / `alger_playlist` | 单曲详情（歌词+直链）/ 歌单详情 |
| `alger_setup` | 音乐服务 check/start/stop（一般无需手动） |
| `alger_say` | 让月宝开口说话 |

## ⚙️ 工作原理

插件加载时自动拉起一个本机音乐 API 服务（默认 `30588`，仅回环），
搜索/歌词/直链/歌单/推荐都走它；播放由浮窗内浏览器 `<audio>` 引擎出声，
进度与状态由服务端状态机统一管理。**没有任何外部播放器依赖。**

## 📦 安装与配置

```bash
dsh plugin --profile web add github:Dongfang81/moony-singer
```

可选配置（`cordis.patch.yml`）：

```yaml
- id: alger-music
  name: 'dsh-moony-singer'
  config:
    musicApiPort: 30588   # 内置音乐 API 端口
    musicApiHost: '127.0.0.1'
    timeoutMs: 20000
```

## ❓ 常见问题

- **音乐服务未就绪？** 插件加载时自动启动；若端口被占用，改 `musicApiPort` 或重启 dsh web。
- **部分歌曲无法播放？** 版权受限的歌曲没有可用直链，换一首即可。
- **不出声？** 浏览器可能拦截了自动播放，点一下播放按钮即可。
